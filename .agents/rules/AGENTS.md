# Project Vibe Coding Rules & Directives

## Project Standards
- **Autonomous Execution**: Build features completely. Don't leave placeholders (TODOs) or mock stubs.
- **Verification First**: Run tests and lint checks after modifications to verify zero regressions.
- **Modular Design**: Keep components small, decoupled, and strictly typed.
- **Preserve Context**: Maintain existing code conventions, folder structures, and comments.

## Stack Guidelines
- Match established patterns in this repository.
- Ensure all public functions, classes, and components have clear type annotations.
- Keep commits formatted with Conventional Commits (feat, fix, refactor, test, chore).
